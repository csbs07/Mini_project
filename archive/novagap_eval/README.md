## 2. Results & Script Mapping

The evaluation outputs located in [`results/`](results/) were generated by the scripts archived in this directory:

### Protocol A / Caliper & Replication Pipeline ([`run_final_pipeline.py`](run_final_pipeline.py))
- `results/table1_openalex_page_order.csv`: Table 1 — Page-order bias demonstration across OpenAlex API queries.
- `results/table2_degree_matched_profiles.csv`: Table 2 — Degree-matched caliper sample profiles and balance metrics.
- `results/table3_logistic_coefficients.csv`: Table 3 — Logistic regression baseline coefficients.
- `results/table4_restricted_caliper_performance.csv`: Table 4 — Link prediction performance under restricted caliper matching.
- `results/table5_multiseed_replication.csv`: Table 5 — Multi-seed replication across independent random seeds (42, 43, 44).
- `results/table6_rq2_citation_regressions.csv`: Table 6 — Research Question 2 citation regressions.
- `results/table_natural_candidates_check.csv`: Natural candidate pool sanity check.
- `results/table_sensitivity_2018_2020.csv`: Temporal sensitivity validation across 2018 and 2020 slices.
- `results/table_unrestricted_caliper_performance.csv`: Performance comparison under unrestricted matching.

### Protocol B Natural-Candidate Evaluation ([`run_natural_protocol_b.py`](run_natural_protocol_b.py))
- `results/table_protocol_b_profiles.csv`: Natural candidate sample profiles and degree-product disparity.
- `results/table_protocol_b_performance.csv`: Model evaluation (AUROC / Average Precision) on natural candidate pairs.
- `results/table_protocol_b_transfer_coefficients.csv`: Transfer failure analysis for caliper-fit logistic regression.

### Supporting Modules
- [`audit_pilot.py`](audit_pilot.py): Core metric computations, graph algorithms, and evaluation routines.
- [`run_fast_tables5_6.py`](run_fast_tables5_6.py): Fast execution harness for Tables 5 & 6 replication.
- [`fetch_all_seeds.py`](fetch_all_seeds.py): Deterministic multi-seed OpenAlex API sampling fetcher.
- [`dataset_builder.py`](dataset_builder.py), [`evaluator.py`](evaluator.py), [`metrics.py`](metrics.py): Component modules.
